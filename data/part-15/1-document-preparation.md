## Адрес проекта

https://github.com/stud-labs/logtalk-lab-gen

## Постановка задачи

**Цель работы.** Разработать на Logtalk генератор справок для группы магистрантов: по данным об успеваемости и учебному плану получить файл LaTeX, который без ошибок компилируется в PDF.

**Исходные данные.**

- группа студентов: идентификатор, ФИО в именительном и дательном падежах, пол и дата рождения;
- ведомость: для каждого студента — список пар «дисциплина — оценка» (`5`, `4` или `ok`);
- учебный план: курс, направление и шифр специальности, институт и кафедры, сроки обучения, приказ о зачислении, преподаватели;
- список генерируемых документов и уполномоченное лицо для подписи.

**Что требуется сделать.**

1. Описать объекты предметной области: группу, ведомость, учебный план и организационную структуру института.
2. Определить протокол отрисовщика, не зависящий от LaTeX: открытие и закрытие потока, преамбула и заключение, новая страница, команды и текст.
3. Реализовать два документа — справку об успеваемости и справку об обучении — так, чтобы они читали данные из объектов, а не из зашитых констант.
4. Собрать диспетчер, который для каждого студента группы формирует оба документа в один выходной файл.

**Результат.**

- исходные файлы Logtalk;
- файл `doc-anon.tex`, собираемый командой `lualatex doc-anon.tex`;
- PDF, в котором для каждого студента есть обе справки;
- короткий отчёт: структура объектов, команда запуска, известные ограничения.

**Критерии готовности.**

- документ компилируется LuaLaTeX без ошибок, нарушающих вёрстку;
- на каждого студента из группы формируются обе справки;
- ФИО подставляется в правильном падеже, дата выводится в формате ДД.ММ.ГГГГ;
- в справке об успеваемости перечислены все дисциплины учебного плана с оценками и подсчитаны итоги;
- реквизиты организации, специальность и подписант берутся из данных, а не зашиты в отрисовщике;
- генерация запускается одной целью `documents_anon::gen` (или аналогичной), без ручных правок между запусками.

**Ограничения и упрощения.**

- одна учебная группа и один учебный план;
- русский язык документов, шаблон LaTeX фиксирован;
- веб-интерфейс, база данных и авторизация не требуются;
- если в системе нет шрифтов или логотипа из примера, разрешается заменить их на доступные, сохранив структуру документа.

**Этапы работы.**

1. Данные: группа, ведомость, учебный план, институт (разделы 1–2).
2. Документы: общий сценарий, справка об успеваемости, справка об обучении (раздел 3).
3. Отрисовщик: протокол и реализация `latexRenderer` (раздел 3).
4. Проверка: сборка PDF, сверка данных, прогон на другой группе.

**Вопросы для самопроверки.**

- Почему данные, документы и отрисовщик разделены на разные объекты?
- Что произойдёт, если в ведомости появится дисциплина, которой нет в учебном плане?
- Как добавить новый формат вывода, не меняя код документов?

В качестве примера рассмотрим задачу порождения документов для формирования заявки на гранты Потанина для студентов-магистров.

## Реализация требований уровня пользователя

Пользователем программы является секретарь, программирующий на Logtalk. Это звучит абсурдно, но пока примем такие требования. В дальнейшем систему можно улучшить, добавив веб-интерфейс.

Итак, нам нужно распечатать документ — например, сгенерировать PDF-файл. Самый простой способ сделать качественный документ — использовать LuaLaTeX. Благодаря тому, что исходный код документа представляет собой обычный UTF-8-текст, а формат настраивается в отдельном файле (существуют десятки способов сделать настройку удобной, правильной, быстрой и точной), сгенерировать документ достаточно просто. Исходные данные для генератора — структура группы, оценки и список документов, адаптированных под университет и институт.

### Объект, представляющий группу студентов

Студенты задаются по шаблону: имя в именительном и родительном падежах в виде списка опций (см. раздел «Стандартная библиотека»), пол и дата рождения. Первый аргумент ```el/4``` — идентификатор студента.

```logtalk
:- object(group_anon,
   extends(studentGroup(02299-'ДМ'))). % TODO: определить объект группы в проекте.

   el(maz, student([nom='Иванова Наталья Александровна',
                    dat='Ивановой Наталье Александровне'], f, 1987-05-30)).
   el(kur, student([nom='Петрова Елена Максимовна',
                    dat='Петровой Елене Максимовне'], f, 1983-12-12)).
   el(pop, student([nom='Сидоров Николай Петрович',
                    dat='Сидорову Николаю Петровичу'], m,  1999-09-13)).
:- end_object.
```

База данных оценок по предметам представляется объектом ```notes/2```. Первый параметр — идентификатор студента, второй — список опций с оценками. Предметы в списке являются ключами и задаются идентификаторами.

```logtalk
:- object(notes_anon,
   implements(notesp)).

   notes(kur,
    [
        akm-5, is-5,

        fl1-ok, com-4, cmm-4, tpc-ok,
        iot-4, ddb-5, ml-5, spr-5,

        dis-5, sw-4, ssp-5,

        ais-5, fl2-ok, rec-5, rnd-ok,
        nn-5, ds-5, dda-5, kp1-5, ppr-5
    ]).
   notes(maz,
    [
        akm-5, is-5,

        fl1-ok, com-5, cmm-5, tpc-ok,
        iot-5, ddb-5, ml-5, spr-5,

        dis-5, sw-4, ssp-5,

        ais-4, fl2-ok, rec-4, rnd-ok, nn-4,
        ds-4, dda-4, kp1-5, ppr-5
    ]).
   notes(pop,
    [
        akm-5, is-5,

        fl1-ok, com-5, cmm-5, tpc-ok,
        iot-5, ddb-5, ml-5, spr-5,

        dis-5, sw-4, ssp-5,

        ais-5, fl2-ok, rec-5, rnd-ok,
        nn-5, ds-5, dda-5, kp1-5, ppr-5
    ]).
:- end_object.
```

### Представление списка документов для генерации

Собственно задача — сгенерировать документы для анонимной группы.

```logtalk
:- object(documents_anon).
   :- use_module(library(lists), [member/2]).
   :- public(gen/0).
   gen :-
       % debugger::trace,
       forall(member(FileName,['doc-anon.tex']), % можно использовать user
       % forall(member(FileName,[user]),         % для вывода на экран
              potaninDocuments(latexRenderer(FileName), % в какой формат
                   notes_anon, group_anon,              % документы
                   curriculum2023,   % учебный план (здесь предметы описаны)
                   fal)::gen).

   :- initialization(gen).  % инициализация
:- end_object.
```
