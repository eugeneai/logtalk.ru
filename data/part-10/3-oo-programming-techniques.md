- Размещать грамматики в объектах и категориях
- Комбинировать грамматические правила с состоянием объекта
- Строить разборщики для небольших языков
- Использовать грамматики как генераторы

</text-box>

DCG-правила можно размещать внутри объектов. Это даёт пространство имён, повторное использование и возможность комбинировать грамматику с методами объекта.

## Грамматика в объекте

```logtalk
:- object(greeting_parser).

    :- public(greeting//1).

    greeting(Name) --> [hello, Name].

:- end_object.
```

Вызов:

```logtalk
?- greeting_parser::greeting(Name, [hello, world], []).
Name = world.
```

Правило `greeting//1` объявлено публичным. Внутри объекта оно компилируется в предикат `greeting/3` с двумя дополнительными аргументами списка.

## Арифметический разборщик

```logtalk
:- object(arithmetic_parser).

    :- public(number//1).
    :- public(sum//1).

    number(N) --> [N], { number(N) }.

    sum(N) -->
        number(A),
        ['+'],
        number(B),
        { N is A + B }.

:- end_object.
```

Запросы:

```logtalk
?- arithmetic_parser::number(N, [7], []).
N = 7.

?- arithmetic_parser::sum(N, [2, '+', 3], []).
N = 5.
```

Такой разборщик легко расширить: добавить `'-'`, `'*'`, скобки или приоритеты операций.

## Грамматика и категории

Если грамматика используется несколькими объектами, её можно вынести в категорию:

```logtalk
:- category(greeting_grammar).

    :- public(greeting//1).
    greeting(Name) --> [hello, Name].

:- end_category.

:- object(parser1, imports(greeting_grammar)).
:- end_object.

:- object(parser2, imports(greeting_grammar)).
:- end_object.
```

Оба объекта получают правило `greeting//1` без дублирования кода. Это тот же приём композиции, что и для адаптеров.

## Грамматика и состояние

Грамматические правила могут обращаться к параметрам объекта или его динамическим предикатам:

```logtalk
:- object(number_parser(_Base_)).

    :- public(number//1).

    number(N) --> [N], { number(N), N >= _Base_ }.

:- end_object.
```

Параметр `_Base_` задаёт минимальное допустимое число. Один и тот же разборщик используется с разными ограничениями.

## Разбор и генерация

DCG можно использовать для генерации корректных последовательностей:

```logtalk
:- object(sentence_generator).

    :- public(sentence//0).

    sentence --> [hello], [world].

:- end_object.
```

Запрос с несвязанным списком перебирает допустимые последовательности. Для продуктивной генерации добавляйте ограничения и следите за завершаемостью.

## Практические советы

- Начинайте с маленькой грамматики и постепенно добавляйте правила.
- Используйте `{}` для вычислений и проверок, а не для побочных эффектов.
- Тестируйте разбор и генерацию отдельно.
- Для больших языков выносите грамматику в отдельные категории.

## Что важно запомнить

- DCG-правила можно размещать в объектах и категориях.
- Публичные правила объявляются с `//`.
- В объекте вызов выглядит как `Object::NonTerminal(Args, List, Rest)`.
- Категории позволяют переиспользовать грамматику.
- Параметры объекта и динамические предикаты связывают грамматику с состоянием.
