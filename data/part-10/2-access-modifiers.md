**DCG** (Definite Clause Grammar) — это способ записывать грамматики прямо в Prolog и Logtalk. Правило DCG выглядит как обычное правило, но вместо `:-` использует `-->`:

```logtalk
greeting(Name) --> [hello, Name].
```

Это правило говорит: «список начинается с терминала `hello`, затем идёт произвольный элемент `Name`».

## Терминалы и нетерминалы

- **Терминал** — конкретный элемент списка, например `hello` или `'+'`.
- **Нетерминал** — вызов другого грамматического правила.
- **Действие** `{Goal}` — обычная Prolog-цель, которая выполняется во время разбора.

Пример:

```logtalk
:- object(arithmetic_grammar).

    :- public(number//1).
    :- public(sum//1).

    number(N) --> [N], { number(N) }.

    sum(N) -->
        number(A),
        ['+'],
        number(B),
        { N is A + B }.

:- end_object.
```

Правило `sum//1` разбирает число, знак `+` и ещё одно число, после чего вычисляет сумму.

## Вызов грамматики

DCG-правило `sum//1` компилируется в предикат `sum/3`: два дополнительных аргумента — входной и остаточный список. В объекте его можно вызвать напрямую:

```logtalk
?- arithmetic_grammar::sum(N, [2, '+', 3], []).
N = 5.
```

Третий аргумент `[]` означает, что весь список должен быть разобран без остатка.

Для грамматик в plain Prolog используется `phrase/2-3`:

```prolog
?- phrase(sum(N), [2, '+', 3]).
N = 5.
```

В Logtalk объектный вызов `Object::NonTerminal(Args, List, Rest)` обычно удобнее, потому что имя объекта задаёт пространство имён.

## Генерация списков

DCG можно использовать не только для разбора, но и для генерации:

```logtalk
?- arithmetic_grammar::sum(N, List, []).
```

Если `List` не связан, правило будет перебирать варианты. Однако для генерации нужны дополнительные ограничения, иначе перебор может быть бесконечным.

## Рекурсивные грамматики

DCG естественно поддерживают рекурсию:

```logtalk
:- object(list_grammar).

    :- public(items//1).
    items([X|Xs]) --> [X], items(Xs).
    items([]) --> [].

:- end_object.
```

Запрос:

```logtalk
?- list_grammar::items(Items, [a, b, c], []).
Items = [a, b, c].
```

## Действия и проверки

В `{...}` можно выполнять проверки:

```logtalk
positive(N) --> [N], { number(N), N > 0 }.
```

Если проверка не проходит, правило завершается неудачей.

## Что важно запомнить

- `-->` описывает грамматическое правило.
- Терминалы — элементы списка, нетерминалы — другие правила.
- `{Goal}` выполняет обычную Prolog-цель.
- В объекте DCG вызывается как `Object::NonTerminal(Args, List, Rest)`.
- DCG подходит и для разбора, и для генерации.
