Поиск в ширину перебирает все состояния по порядку. Для больших задач это слишком медленно. **Эвристический поиск** использует оценку близости к цели и сначала исследует перспективные состояния.

## Оценка

Для узла хранят:

- `g` — стоимость пути от начала;
- `h` — эвристическую оценку стоимости до цели;
- `f = g + h` — приоритет узла.

Чем меньше `f`, тем раньше узел должен быть обработан.

## Эвристика

Эвристика должна быть:

- **допустимой** — не переоценивать реальную стоимость до цели;
- **согласованной** — для каждого действия `h(State) <= cost(Action) + h(Next)`.

Для задачи о перемещении робота по сетке подойдёт манхэттенское расстояние:

```logtalk
heuristic(at(X1, Y1), at(X2, Y2), H) :-
    H is abs(X1 - X2) + abs(Y1 - Y2).
```

Для произвольного графа можно использовать расстояние по прямой или заранее вычисленную таблицу.

## Очередь с приоритетом

Кучи из библиотеки `heaps` подходят для выбора узла с минимальным `f`:

```logtalk
:- object(astar).
    :- use_module(library(lists), [member/2]).

    :- public(push/3).

    push(Heap0, Priority, Node, Heap) :-
        pairing_heap_min::insert(Priority, Node, Heap0, Heap).

    :- public(pop/4).

    pop(Heap0, Priority, Node, Heap) :-
        pairing_heap_min::delete(Heap0, Priority, Node, Heap).

:- end_object.
```

В реальном планировщике узел хранит состояние, план и стоимость `g`, а ключ кучи — `f`.

## Алгоритм

1. Поместить начальный узел в кучу с приоритетом `h(Start)`.
2. Извлечь узел с минимальным `f`.
3. Если достигнута цель — вернуть план.
4. Для каждого допустимого действия создать соседний узел.
5. Посчитать `g' = g + cost`, `f' = g' + h(Next)`.
6. Добавить узел в кучу, если он ещё не обработан или найден более дешёвый путь.

## Оптимальность

A* находит оптимальный план, если эвристика допустима. Если эвристика ещё и согласована, узел можно не переоткрывать после обработки.

Если эвристика равна нулю, A* превращается в поиск Дейкстры. Если эвристика переоценивает стоимость, план может быть неоптимальным.

## Что важно запомнить

- Эвристика оценивает расстояние до цели.
- Приоритет узла — `f = g + h`.
- Для очереди с приоритетом удобно использовать кучу.
- Допустимая эвристика не переоценивает стоимость.
- A* оптимален при допустимой эвристике.
