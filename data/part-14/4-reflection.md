<text-box variant='learningObjectives' name="Цель изучения раздела">

После изучения этого раздела вы сможете

- Получать список загруженных объектов
- Читать свойства объекта через `object_property/2`
- Исследовать предикаты и их свойства
- Использовать рефлексию для инструментов и отладки

</text-box>

**Рефлексия** — это возможность программы исследовать собственную структуру: объекты, протоколы, предикаты и их свойства. В Logtalk рефлексия встроена в ядро.

## Список объектов

```logtalk
?- current_object(Object).
```

Поочерёдно возвращает все загруженные объекты. Можно отфильтровать только те, которые реализуют нужный протокол:

```logtalk
?- current_object(Object),
   object_property(Object, implements(shapep)).
```

## Свойства объекта

```logtalk
?- object_property(square, Property).
```

Возможные свойства:

- `public(Predicates)` — объявленные public-предикаты;
- `protected(Predicates)`, `private(Predicates)` — другие области видимости;
- `implements(Protocol)` — реализуемые протоколы;
- `extends(Parent)` — родительский объект;
- `file(File, Path)` — файл и строка объявления;
- `number_of_clauses(Number)` — число предложений;
- `number_of_user_clauses(Number)` — число предложений пользователя.

Пример:

```logtalk
:- object(inspector).
    :- public(public_predicates/2).

    public_predicates(Object, Predicates) :-
        object_property(Object, public(Predicates)).

:- end_object.
```

```logtalk
?- inspector::public_predicates(square, Predicates).
Predicates = [side/1].
```

Список свойств зависит от объекта: у протокола, категории и класса он отличается.

## Свойства предикатов

`predicate_property/2` позволяет узнать, является ли предикат встроенным, динамическим, защищённым и т. д.:

```logtalk
?- predicate_property(atom_length(_, _), Property).
```

Для методов объекта используйте контекст объекта и индикатор предиката. Синтаксис `Object::Name/Arity` в `predicate_property/2` не работает: это не индикатор предиката, а терм сообщения.

## Рефлексия и инструменты

Рефлексия полезна для:

- генераторов документации;
- линтеров и анализаторов кода;
- отладочных панелей;
- плагинов, которые ищут объекты с нужным интерфейсом;
- тестов, проверяющих наличие public-метода.

Например, тест может проверить, что объект реализует обязательный протокол:

```logtalk
:- public(implements_protocol/2).
implements_protocol(Object, Protocol) :-
    object_property(Object, implements(Protocol)).
```

## Ограничения

Рефлексия показывает то, что известно компилятору и среде выполнения. Она не заменяет статическую проверку типов и не гарантирует, что метод ведёт себя корректно. Не используйте рефлексию там, где достаточно обычного полиморфного вызова.

## Что важно запомнить

- `current_object/1` перечисляет загруженные объекты.
- `object_property/2` читает свойства объекта.
- `predicate_property/2` читает свойства предиката.
- `Object::Name/Arity` — не индикатор предиката для рефлексии.
- Рефлексия нужна инструментам, плагинам и тестам, а не обычной бизнес-логике.
